# Etapa 1 — Auditoría

## Objetivo
Cerrar la infraestructura y dejarla estable antes de empezar la siguiente etapa.

## Checklist funcional
- [ ] El Excel carga siempre.
- [ ] Si falla la primera carga, se intenta la ruta alternativa.
- [ ] Cada rol muestra solo campeones de su propia hoja.
- [ ] No se pueden repetir campeones.
- [ ] El botón **Limpiar selección** reinicia el estado.
- [ ] La tabla de resultado se actualiza correctamente.
- [ ] El badge de versión abre y cierra el panel de revisión.

## Checklist responsive
- [ ] Escritorio.
- [ ] Tablet vertical.
- [ ] Tablet horizontal.
- [ ] Móvil Android.
- [ ] Móvil iPhone.

## Checklist técnica
- [ ] Sin errores en consola.
- [ ] Sin 404 de recursos.
- [ ] Sin solapes entre paneles.
- [ ] Sin scroll horizontal inesperado.
- [ ] Sin elementos ocultos por `overflow`.
- [ ] Sin duplicidades de lógica.

## Criterio de cierre
La etapa solo se cierra cuando todo lo anterior está marcado y revisado.
