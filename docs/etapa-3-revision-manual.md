# Etapa 3 — Revisión manual

## Objetivo
Confirmar en navegador real que la interfaz visual se ve y responde bien después del pulido de la Etapa 3.

## Preparación
- Abrir la versión publicada en GitHub Pages.
- Hacer un hard refresh (`Ctrl+F5` / `Cmd+Shift+R`).
- Verificar que no aparecen 404 en consola.
- Verificar que `stage3-spacing.css`, `stage3-visual.css`, `stage3-animations.css` y `version.js` se cargan correctamente.

## Revisión en escritorio
- [ ] El encabezado mantiene un buen ritmo visual.
- [ ] Las tarjetas tienen proporciones coherentes.
- [ ] El selector se abre en la posición correcta.
- [ ] El resultado no se solapa con el formulario.
- [ ] El badge de versión queda visible y accesible.
- [ ] No aparecen errores propios en la consola.

## Revisión en tablet
- [ ] El layout conserva espaciados correctos.
- [ ] La tabla sigue siendo legible.
- [ ] No hay scroll horizontal inesperado.
- [ ] El selector no queda detrás de otros bloques.
- [ ] La interacción táctil responde bien.

## Revisión en móvil
- [ ] El contenido cabe correctamente en ancho estrecho.
- [ ] Los inputs y botones tienen tamaño táctil adecuado.
- [ ] El selector sigue siendo usable y visible.
- [ ] La tabla se adapta sin romper la lectura.
- [ ] No hay desajustes visibles entre bloques.

## Criterio de cierre
La etapa queda cerrada cuando la revisión manual no detecta errores de consola ni desajustes visibles en escritorio, tablet o móvil.
