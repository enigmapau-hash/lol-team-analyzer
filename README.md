# LoL Team Analyzer

Mini PWA para analizar composiciones de League of Legends con IA.

## Uso

1. Abre la app.
2. Escribe tu OpenAI API key.
3. Completa Top, Jungle, Mid, ADC y Support.
4. Pulsa **Analizar**.

## Nota

La clave se guarda en `localStorage` del navegador. Esta versión está pensada para uso personal o pruebas rápidas.
